# Product Discovery

> 本文件整理目前對問題、使用者、產品機會與風險的理解。已確認事項與待驗證假設分開記錄，避免把產品推測寫成市場事實。

## 壹、問題理解

企業費用審查並不只是「核對欄位是否符合規則」。

實際初審工作通常同時包含：

- 檢查必要資料與附件是否齊全
- 比對申請內容與單據
- 套用企業費用規範
- 判斷是否需要補件
- 找出異常或需要進一步確認的案件
- 通知、轉交、留下紀錄等後續例行處理

因此，人力成本不只來自「判斷」，也來自判斷前後大量重複操作。

此外，單純規則引擎只能回答「有沒有違反已知規則」，較難處理合理性、歷史異常、疑似重複／拆單、憑證真偽風險或跨系統訊號等需要脈絡的情境。

## 貳、潛在使用者與 Stakeholder

### 主要使用者：財務／會計初審人員

需要快速知道：

- 這筆案件是否需要我處理？
- 哪裡有問題？
- 判斷依據是什麼？
- 下一步該做什麼？

### 管理與決策者：財務主管／會計主管／CFO

關注：

- 是否能減少低價值人工初審
- 是否能控制 AI 自動化風險
- 是否能留下完整可追溯紀錄
- 是否能從案件與人工決策中改善制度
- 是否能在不大幅改造現有系統下導入

### 相關 Stakeholder

**IT／資訊安全**：關注系統整合、權限、資料安全與導入成本。

**內部稽核／風險管理**：關注規則一致性、可追溯性、例外案件與控制機制。

> 上述角色與需求為目前產品假設，仍需透過訪談、實際流程資料與導入測試持續驗證。

## 參、目前觀察到的機會

### 1. 初審工作可以從 Copilot 往 Agent 延伸

如果產品只提供摘要與建議，財務人員仍需自行完成通知、轉交與流程操作。

更有價值的方向是讓 Agent 在清楚的授權與控制條件下，直接完成低風險、可逆且重複性的後續處置。

### 2. 規則之外的風險可能形成差異化

企業規範檢核是必要能力，但容易被既有費用管理系統或規則引擎涵蓋。

CheckMate 更值得驗證的能力包括：

- 合理性（Reasonableness）
- 憑證真偽風險（Authenticity）
- 歷史異常
- 重複申報／疑似拆單
- 跨案件與跨系統風險

### 3. 決策資料本身可能成為長期資產

案件 → Agent 發現項目（Finding）→ 人工決策（Human Decision）→ 覆寫（Override）→ 最終結果（Final Outcome）

若能持續累積上述資料，企業可進一步看見：

- 哪些規範最常造成補件或例外
- 哪些案件類型最常被人工覆寫
- 哪些控制條件可以逐步自動化
- 哪些制度可能與實際業務情境脫節

### 4. 導入方式會直接影響採用門檻

若要求企業先替換 ERP、BPM 或費用管理系統，導入成本與阻力會增加。

因此目前方向是把 CheckMate 定位為既有系統之上的**審查與控制層（Review & Control Layer）**，可從檔案上傳、批次審查開始，再逐步串接 API 或嵌入既有流程（Workflow）。

## 肆、待驗證假設

| 假設 | 為什麼重要 | 驗證方式 |
|---|---|---|
| 財務團隊願意讓 Agent 執行部分後續處置 | 決定代理式價值（Agentic Value）是否成立 | 訪談、原型（Prototype）測試 |
| 佐證鏈（Evidence Chain）足以建立操作信任 | 決定使用者是否敢依結果行動 | 可用性測試（Usability Test） |
| 合理性與歷史風險比單純規則檢查更具差異化 | 決定產品定位（Positioning） | 客訪、競品比較 |
| 低門檻疊加既有系統是重要採購因素 | 決定市場推廣（GTM）與整合策略（Integration Strategy） | CFO／IT 訪談 |
| 人工覆寫（Override）與結果資料能反饋制度改善 | 決定長期資料飛輪（Data Flywheel）是否成立 | 實際案件資料驗證 |

## 伍、目前待確認資訊

- 不同企業實際初審流程與角色分工
- 各類案件量與人工處理時間
- 最常見的補件與例外原因
- 企業願意授權 Agent 自動執行的動作
- Finance、IT、Audit 各自的導入門檻
- 台灣法規檢核中適合 deterministic rule 的項目
- 真偽風險與 Reasonableness 可取得的資料來源
- 現有 ERP／BPM／Expense System 的常見整合方式

## 陸、目前產品判斷

現階段不應追求完整費用管理平台，而應先驗證三件事：

1. Agent 是否能完成一個可信任的初審閉環。
2. 規則外風險是否能提供現有系統沒有的額外價值。
3. 使用者是否願意在明確控制條件下，把部分例行處置交給 Agent。
