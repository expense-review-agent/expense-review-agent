# Original Challenge

## 壹、原始命題

設計一個 **AI 費用單據初審 Agent**，協助企業處理大量費用申請與單據的初步審查。

Agent 需讀取費用申請與相關憑證，依企業規範與可判斷的檢核條件完成初審，並產生可供財務人員採取後續行動的結果。

## 貳、最低能力要求

Agent 至少需要：

1. 讀取費用申請與單據內容。
2. 擷取審查所需欄位。
3. 比對申請內容、憑證與企業規範。
4. 辨識正常、缺件、異常與需要人工判斷的案件。
5. 說明判斷依據，包含對應規範或比對結果。
6. 讓財務人員可以快速辨識哪些案件可繼續處理、哪些需要補件或人工介入。

## 參、Demo 最低要求

使用模擬資料展示至少 5–10 筆具代表性的費用案件，涵蓋：

- 正常案件
- 重複申報
- 超出費用上限
- 缺少必要附件
- 申請金額與單據金額不一致

所有資料須為 Mock Data，不使用真實個人、財務或企業敏感資料。

## 肆、產品限制

本題聚焦在「初審」而非完整費用管理，因此不以以下能力作為必要範圍：

- 最終核准
- 正式會計入帳
- 自動付款
- 正式稅務申報
- 完整 ERP／費用管理系統替換

## 伍、核心問題

本題真正要解的不是「讓 AI 看懂單據」，而是：

> 在不放大錯誤與控制風險的前提下，哪些費用初審工作可以由 Agent 完成，讓財務人員從逐筆檢查轉向處理真正需要專業判斷的例外案件？

後續 Product Discovery、Product Brief 與 Product Scope 均以此問題為起點。
